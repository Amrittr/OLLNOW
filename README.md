# OLLNOW

A website that helps people book rides and cars, and lets car owners rent out their car by the day. Built as a CSE 326 web project.

## Pages

All files are in `CSE 326 web-site project OLLNOW/`:

- `mainfrontpage.html`: home page
- `Login page.html` and `sign up page.html`: account pages
- `Untitled-1.html`, `Untitled-3.html`: additional pages

Static HTML, no build step: open `mainfrontpage.html` in a browser.
